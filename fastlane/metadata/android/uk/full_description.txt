PGPony приносить на Android справжнє шифрування OpenPGP: постквантова криптографія та підтримка апаратних ключів безпеки. Створюйте ключі PGP, шифруйте, розшифровуйте, підписуйте й перевіряйте повідомлення та файли просто на пристрої. Без облікового запису, без сервера, без стеження. Повністю сумісний із GnuPG (GPG), OpenKeychain та іншими інструментами OpenPGP.

НОВЕ: поєднання з PGPony Desktop, вхід через SSH з ключами PGP та постквантові підписи ML-DSA.

▌ПОСТКВАНТОВЕ ШИФРУВАННЯ
- Композитні ключі шифрування ML-KEM-768 і ML-KEM-1024 (Kyber)
- Постквантові підписи ML-DSA-65 і ML-DSA-87 (Dilithium) на ключах OpenPGP v6
- Стандартний формат IETF і формат LibrePGP, який використовує GnuPG 2.5
- Захист від атак «збери зараз, розшифруй потім»

▌ПОШТА, ПАРОЛІ ТА SSH
- Провайдер OpenPGP для Thunderbird для Android, K-9 Mail і FairEmail
- Сучасний наступник OpenKeychain: той самий API, активна підтримка
- Кожен підключений застосунок ви схвалюєте самі й можете відкликати в налаштуваннях
- Читання записів pass (password-store), зокрема прив'язаних до апаратного ключа
- Вхід через SSH з ключем PGPony через ssh-agent у Termux

▌АПАРАТНІ КЛЮЧІ БЕЗПЕКИ
- YubiKey, Token2 чи інша смарт-картка OpenPGP через NFC або USB
- Закритий ключ ніколи не залишає пристрій; PIN підтверджує кожну операцію
- Створення ключів на картці, підпис і розшифрування; кеш PIN за бажанням
- Зміна PIN і скидання картки; підтримка PIN із захистом KDF

▌КЕРУВАННЯ КЛЮЧАМИ PGP
- Створення пар ключів Ed25519, RSA, OpenPGP v6 або постквантових
- OpenPGP v4 (RFC 4880) і v6 (RFC 9580), AEAD-OCB та Argon2id
- Імпорт і експорт ключів; підключі та User ID; термін дії; відкликання
- Зашифрована резервна копія й відновлення, зокрема копій OpenKeychain

▌ШИФРУВАННЯ, РОЗШИФРУВАННЯ, ПІДПИС
- Шифрування тексту й файлів для одного чи кількох одержувачів
- Перевірка підписів із чіткою позначкою перевіреного підписувача
- Пошта PGP/MIME: розшифрування листів із вкладеннями, створення .eml

▌ПРОСТИЙ ОБМІН КЛЮЧАМИ
- Публічний ключ як QR-код, файл або текст; скануйте, щоб імпортувати
- Імпорт ключа за посиланням із перевіркою відбитка перед додаванням
- Пошук на серверах ключів і через Web Key Directory (WKD), зокрема keys.openpgp.org
- Поєднання з PGPony Desktop (macOS, Windows, Linux) або іншим телефоном
- Autocrypt і вбудований список контактів

▌ПРИВАТНІСТЬ ЗА ЗАМОВЧУВАННЯМ
- Шифрування на 100% на пристрої: без облікового запису, без телеметрії
- Офлайн-режим вимикає всі мережеві функції
- Трафік до серверів ключів через Tor з Orbot
- Закриті ключі в зашифрованому сховищі на основі Android Keystore
- Біометричне блокування, відбиток для підпису, автоочищення буфера обміну

▌ДЛЯ КОГО PGPONY
- Журналісти, дослідники й активісти, які працюють із чутливою інформацією
- Розробники й адміністратори, які підписують PGP код, релізи або входять через SSH
- Користувачі GnuPG, яким потрібен мобільний помічник або заміна OpenKeychain

▌ЧОМУ PGPONY
Більшість «захищених месенджерів» просять довіряти їхнім серверам. PGPony сервери не потрібні. Ключі створюються й зберігаються на вашому пристрої та залишають його, лише якщо ви ними поділитеся. Якщо ви користуєтеся GnuPG на комп'ютері, ви вже знаєте PGPony. Новачок у PGP? Тут найпростіше почати.

▌ВІДКРИТИЙ КОД
- Ліцензія Apache-2.0, ядро OpenPGP опубліковано окремою бібліотекою
- Відтворювані збірки: будь-хто може звірити APK з вихідним кодом
- Безкоштовно, без реклами та вбудованих покупок

▌ЗОБОВ'ЯЗАННЯ ЩОДО ПРИВАТНОСТІ
PGPony не збирає, не зберігає й не передає персональних даних. Політика конфіденційності: pgpony.app/privacy
